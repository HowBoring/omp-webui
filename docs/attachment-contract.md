# 图片与文件输入合同目标

Status: 用户已确认 Q1–Q10，附件决策完成；以下为合同目标，产品尚未实现。
日期：2026-11-16（Asia/Singapore）。工单：[图片与文件输入：格式范围、RPC 链路与存储边界](https://github.com/HowBoring/omp-webui/issues/28)。

## 已确认产品政策

| 决策 | 已确认范围 |
| --- | --- |
| Q1 格式与处理 | PNG/JPEG/WebP/GIF、UTF-8 文本/源码，以及 OMP 已有转换路径的 PDF/DOCX/PPTX/XLSX/EPUB；由 OMP 转换或工具读取。截断、转换失败和不支持格式明确显示；不新增 Host OCR、音视频或压缩包解析，不承诺文档全文进入模型 |
| Q2 历史原件 | 已发送原件按已选保留政策支持跨 Host 重启的历史预览或下载；Host 保存原件及必要的 Session/附件关联，模型实际收到的内容以 OMP 历史为准，不复制聊天记录 |
| Q3 添加时机 | 先显式新建/打开会话，确认原生身份后才开放上传、粘贴和拖入；添加附件不隐式创建会话。忙时可准备附件草稿，不接受发送入队 |
| Q4 保存期限 | 已确认写入原生消息的原件默认不按时间自动过期；未发送且没有执行或待确认提交引用的暂存原件，按 Q9 时钟满 24 小时后可清理 |
| Q5 空间预算 | 默认 10 GiB，计入 Host 管理的原件、派生文件及暂存；满时拒绝新增并提示清理，不自动淘汰历史原件。主动删除需明确提示历史失去原件访问，不修改 OMP 聊天记录；删除范围和占用规则遵守 Q8 |
| Q6 上传目标 | 单图原件 10 MiB，单个文本/文档 5 MiB，每条最多 8 个附件，原件总计不超过 32 MiB；这是待实测的首版验收目标。解码、模型和编码后 RPC 预算另行校验；超限保留草稿并明确拒绝，不静默丢附件。未通过门禁时须补齐能力或重新讨论目标 |
| Q7 草稿恢复 | 按页签＋Session 隔离；同页刷新或 Host 重启后恢复文字及仍有效的附件引用，重新准备回执，失效项明确提示且不自动发送；关闭页面或浏览器后不承诺恢复 |
| Q8 主动删除 | 删除该对象的 Host 保存数据并使其历史关联失去原件访问；不修改 OMP 原生记录或已保存模型输入。展示本 Host 已知影响并确认，提示后续工具重读可能失败。相关执行、已知占用或提交结果未明时拒绝；解决后由用户重新发起，不后台排队删除 |
| Q9 清理时钟 | 未发送暂存的 24 小时从最近一次明确编辑或主动恢复相关草稿起算；刷新、重连、后台读取不续期，Host 重启不重置。执行使用、待确认提交或已关联原生消息的对象不按普通未发送暂存清理 |
| Q10 准备与准入 | 所有附件完成校验及必要的 OMP 准备后才准入 prompt；失败保留草稿，用户重试或移除失败项。截断等影响内容的降级须用户明确接受后继续，不静默只发文字。通过公开兼容构建补齐准备结果与提交保证；模型/工具开始后不承诺回滚 |

“格式支持”是待验证的产品目标，不是已有完整浏览器＋OMP 闭环证据。原件大小与模型/RPC 输入预算是不同约束。
已发送原件的确认、关联提交与失败恢复必须依据原生事实，不能仅把上传完成或 prompt ack 当成持久消息已提交。

## 既有边界

- 上传只进入 Host 配置的专用私有暂存/附件区域，不按浏览器文件名写入或覆盖项目文件。
- 附件归属与当前浏览器、Session、工作目录权限分别校验；对象 ID、hash 或已登录状态不能单独充当读取权限。
- Host 保存原件不构成第二份 transcript；原生消息、模型输入事实、工具执行和树仍由 OMP 保存，通过公开 RPC 获取。
- 图片原件与调整尺寸、重编码后的模型图像分开；文档原件与转换、截断或跳过的内容分开。
- 采用实际 DSH binary/base64、回执和 Remote 合同；当前 OMP 普通文件路径为原生文本引用，不虚构通用文件上传 RPC。
- 全局 OMP 与公开兼容构建仍遵守[RPC 交付门禁](rpc-delivery-contract.md)。缺失能力通过公共扩展和验证解决。

## 保留与预算的含义

Host 的附件预算覆盖其自有附件数据，不能据此宣称限制了 OMP 原生历史、blob、工具输出或整个磁盘占用。
对象正在执行使用、可能已提交而结果未明或仍待原生事实核对时，不将其误判为普通未发送暂存删除。
上传完成、回执就绪、输入准入、原生消息提交和执行完成是不同阶段；原件保留状态须依实际阶段转换。

原件预算与发往 OMP 的输入预算分开。原始文件未超限，也可能因图像解码、所选模型或完整编码后的 RPC 限额而无法发送。
超过后者时保留草稿并说明原因，不偷偷减少附件或将上传成功冒充模型已接收。

## 固定上游事实

OMP 固定为 `7c49c11aa5bbaf3f418406583096168ad5b8c6dc`，DSH 固定为 `38a6a5c965aa99ab525161efb7cc5cf1fe62fced`。
以下为源码核对，不代表真实 worker、转换、上传、持久化或浏览器实验通过。

- OMP `prompt` 接受 message 和可选内联 images，没有通用普通文件对象或下载原件的独立 RPC。原生 `@path` 确实经过 RPC prompt 路径。
- 当前普通文本/文档自动读取在 5 MiB 以上跳过；常规文本输出有 3,000 行/50 KiB 截断。支持的原生文档转换扩展名为 PDF/DOCX/PPTX/XLSX/EPUB；这不保证原始字节或全文成为模型输入。
- 公开 `fileMention` 保留 path、content、lineCount、byteSize、skippedReason 和可选 image。转换失败没有独立结构化转换错误码，截断是内容提示；不存在/不可读路径可能静默省略。需要足够公共结果才能满足本合同的可见失败要求，不从缺席推断具体原因。
- 原生用户图片可能经过处理并保存到原生 blob；普通文档历史保存处理结果和引用，不是原件档案。大 image mention 的持久化还需隔离回读验证。
- DSH 会先发布存储对象再建立内存回执；回执不保证跨 Host/Session 实例重启有效，已发布对象不会因回执丢失自动清理。
- DSH 图片存储可能规范化原始字节；普通文件历史卡片不等于原件下载功能。其既有 image attachment 读取只把 Session ID 当 Gateway 权限作用域，没有本项目所需的实际对象归属保证。
- OMP stdin 使用未分块 JSONL。文档建议客户端保持在 1 MiB 内，当前输入解析器并不实施同名硬字节上限；stdout 物理行/逻辑重组另有限制。完整编码大小必须包含 base64、转义、元数据和换行。

## 草稿、回执与提交状态

- 草稿按页签和真实 Session 身份隔离，并区分 Host/配置上下文；旧上下文不能仅凭同一个显示名称或 Session ID 自动绑定到另一原生来源。
- 浏览器保存语义草稿和稳定原件引用，不保存可长期重放的旧回执。恢复前重新确认身份、当前权限、对象状态和完整性；原件过期、删除或缺失时保留可恢复文字，标明失效项。
- 同页刷新触发的恢复展示不算主动恢复，不延长 Q9 时钟。离线编辑不能预先延长 Host 尚未确认的保留期限；不能把已回收对象复活或悄悄改为另一原件。
- 恢复只作用于匹配代次、仍可编辑的未发送草稿，不覆盖用户已经编辑的新版本，不把提交中的快照变成新输入。切换 Session 不自动转移草稿或复用另一目标的回执。
- 回执重新准备与 prompt 重新发送是不同动作。上传可以在明确的对象/目标/操作身份下实现幂等，但 OMP 请求 ID 不能自动视为持久幂等键；未知 prompt 结果不自动补发。
- 上传取消要使迟到结果失效并清理临时写入，不能仅关闭浏览器指示器。已发布但未返回回执的对象也进入有界跟踪；原生提交结果未知时保护对象并核对原生事实，不据时间或缺席猜成未发送。
- 发送成功关联不能依据文本、时间、相邻 entry、处理后图片 hash 或进程内 messageId 猜测。必须由公共 RPC 提供可恢复的提交身份、实际原生 entry 身份与提交/未生成输入等结果。
- `prompt` ack、`prompt_result`、`get_entries` 中出现某项均不单独证明已持久提交。当前 OMP 可先加入内存，首次会话可延迟落盘，写入失败也可能保留内存项；错误 notice 不等于逐项持久成功凭证。

## 原件删除与历史呈现

- 删除作用于选定原件对象及其逻辑关联，不按文件名或相同内容 hash 误删另一独立原件。存储去重也不能合并权限或逻辑删除范围。
- 删除前展示本 Host 已知引用和影响，不声称已经枚举所有外部 TUI、历史复制或文件使用者。已知相关占用、执行或提交结果未知时拒绝操作；不杀外部进程、不排队等候自动删除。
- 删除后旧回执和新增读取必须失效，历史保留必要的失效关联以显示原件不可用；物理回收不能破坏其他独立对象仍有权使用的数据。回收完成前仍计入实际空间占用。
- 不删除 OMP 已存模型输入、原生消息、工具复制到项目的文件或用户已下载副本，不声称擦除所有副本。没有原件不等于原生整条消息不存在。
- 原件、模型图像、已提取文本须明确区分。安全可预览的格式提供预览，不能安全预览时提供下载或明确原因；HTML/SVG/脚本不得作为同源可执行页面。
- 已导入 TUI 历史只呈现公共 RPC 实际可用内容；没有经验证的原件关联时显示原件不可用，不按文件名、路径或相似图像猜原件，也不扫描 Session 文件或暴露任意路径下载。
- 所有读取、预览和下载继续校验当前浏览器、目录、Session 和对象权限。附件界面不能绕开占用期间的历史访问政策，资源 ID/hash 不能独立充当权限。

## 准备完成后才准入

所有附件完成校验和必要原生准备后才准入 prompt。失败时保留草稿，用户重试或移除失败项；
截断等影响内容的降级由用户明确接受后继续，不静默只发送文字。模型/工具开始后的错误仍可能已有副作用，不能承诺回滚。

确认必须对应实际准备结果；草稿、对象内容、目标、权限或预算变化后重新验证，不能沿用旧确认。
准备与恢复本身不自动发送，不将已接受部分附件误记为整条输入已就绪。准备覆盖明确的校验、转换或
引用准备，不承诺后续工具读取均成功，也不承诺文档全文已入模。

该政策已确认，但固定上游尚无满足它的独立公共准备/消费合同；需要在已选公开兼容构建中补齐并验证。

## 所需公开扩展与工程门禁

以下是语义要求，不是已经存在的新方法名或字段。缺少保证时必须报告能力未就绪，不导入 Agent SDK 或读取原生 Session 文件补洞。

1. **可恢复的原生关联与提交结果**：公开客户端提交身份到实际原生 entry 的稳定映射，并区分输入已提交、未生成输入、持久化失败和未决结果。确认与重启查询须足以恢复原件关联，不依赖进程内 msg-N 或文本匹配；Host 只保存必要索引，不保存第二份聊天。
2. **准备与消费**：公开逐附件准备结果、可判定失败/截断及执行消费保证；文件缺席、转换失败、准备后变更和目标/权限/预算变化不得伪报成功。准备与执行绑定，不能重跑一次不同准备却沿用旧确认。准备本身不启动 Agent 的模型/工具执行，不先制造已提交会话消息。
3. **用户文字与附件来源**：原生 slash、模板、扩展和手工 @path 仍有实际语义；适配器不能用浏览器文件名拼接指令或猜测后缀后删除用户文字。需要时通过公开来源/关联元数据区分原生文字和受控附件引用，不在 Host 复制 transcript。
4. **DSH 草稿公开接缝**：当前实现只在按 Session ID 共享的 localStorage 中保存语义文字，不保存 runtime 附件。需要窄接口承载语义快照、有序稳定原件引用、向确认 binding 的原子恢复，以及新的回执就绪/失效状态；配置持久化归属和键，避免旧共享存储破坏页签隔离。不访问私有 registry、覆盖实例或重写核心 Conversation。
5. **匹配交付**：Native wire/schema/handler/client、DSH 补丁/资产和 Host 按同一组合验证；继续复用经精确门禁的全局 OMP。新原生数据元信息还须验证 TUI、tree/navigation/branch、升级与回退兼容；branch 等复制原生消息后以公共来源事实恢复关联，不猜测新旧 entry 对应。不能将旧官方 release 宣称已有这些保证。

公开 DSH 恢复接缝在源码层面有窄扩展路线，但尚未经过实现和浏览器实验。若实施需要大范围私有适配或核心 Conversation 重写，返回客户端组合决策，不能静默扩范围。

## 验收证据要求

- 固定源、公开补丁、schema、可执行/runtime 闭包与客户端 manifest 一致；静态阅读、fake Remote、真实 RPC 和产品浏览器闭环分别标注，不互相替代。
- 所有已选格式的边界样本、伪装 MIME、错误编码、损坏/空文件、文档转换失败、截断、图像规范化及不支持格式；原件下载 hash 与上传一致，模型表示与原件不得混称。
- 原件/计数/总量、解码/模型/完整 UTF-8 JSONL（含 base64/转义/元数据/换行）和输出分块预算；配额并发预留、临时/派生数据、满额拒收、对象数/元数据及日志有界。
- 上传中取消、发布后回执丢失、重复请求、不同内容复用操作身份、准备/发送边界和旧权限；不得只测最终 UI 状态。
- 多附件中任一准备失败时整条输入不准入，草稿完整保留；截断等降级未确认时不执行。确认后准备版本变化、旧确认迟到、取消/撤权与消费竞争均重新验证或明确失败；实际执行消费已确认结果，不静默只发文字或因再次转换而发送不同内容。
- 同页刷新、Host/worker 重启、两页同 Session 隔离、切换和陈旧恢复；旧回执失效、缺失原件不丢整条草稿、恢复不自动发送；关闭页面不假称可找回。
- 持久化失败、用户输入尚在内存、ack 丢失、提交后崩溃、扩展额外消息、重复文字、进程 messageId 重用；公开结果必须能正确关联和恢复，未决对象不可误清理。
- 24 小时边界、显式编辑/主动恢复与只读刷新、重启继续计时、活动/未决保护、GC 与消费/删除竞态；过期和回收不静默替换附件。
- 明确删除的已知影响、共享存储安全、占用拒绝、重复/迟到确认、旧下载/回执和原生历史保持；历史/分支/TUI 缺原件、处理后图片与原件不同、large image mention 回读。
- 真正的浏览器 raw/base64 上传、准备、人工发送、消息关联、历史预览/下载与重新打开，运行在实际已验证的全局 OMP 兼容构建；不得用 SDK、Session 文件扫描或任意路径下载代替。
