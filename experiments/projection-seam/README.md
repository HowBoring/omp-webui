# Same Session projection rebuild

Ticket #40 adds a disposable projection lifecycle inside the retained DSH execution scope. It keeps the native Session identity and exact SessionReference ownership semantics. Authoritative typed control invalidation names the next branded source/generation; retries target only that authority. See [ADR 0015](../../docs/adr/0015-retain-execution-replace-projection.md).

Old history and projection rows withdraw before cancellation callbacks run. A new journal, complete projection baseline and mandatory assistant baseline publish together. Old pages, assistant envelopes and projection writers are fenced by generation. Independent in-memory drafts, ordered originals and unresolved submission records remain in their input shell; generation changes cancel old provider work and preserve stable storage keys without automatic send or retention renewal.

The controlled public Remote/provider browser matrix passes 13 checks. The actual native/Bun/full built DSH graph passes six combined Chromium checks with three views, multiple holders, a real builtin Ask, the accepted InteractionBridge and a separate real Gateway Agent invocation. Native context change rebuilds in place; idle native branch navigation withdraws off-branch rows. Final browser-holder release and a new holder keep the same native Session and worker. Native cut durability remains `not_attested`.

The native process is guarded before imports, uses a fixed literal in-process provider, and exits code 0 without forcing. Its compressed raw network trace has zero Internet connects/sends; the guard records zero actual network dispatches. This is isolated synthetic component evidence. Product/private Session admission, durable navigation, real-provider inference, global installation and deferred Windows acceptance are separate work.
